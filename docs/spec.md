# 产品与 Agent 需求规格

## 1. 产品定位

为已授权的 VALORANT 国际服竞技玩家提供赛后复盘。产品将确定性统计与一个受约束的分析 Agent 结合，回答玩家“哪里出了问题、证据是什么、下一步练什么”。

## 2. 第一版范围

### 支持

- Riot RSO 登录和玩家本人数据授权。
- 竞技模式对局同步。
- Act 维度的段位推断、趋势和指标。
- 单局和逐回合复盘。
- ADR、ACS、K/D、KAST、爆头率、首杀率、首死率、攻守和经济局分析。
- 个人历史基准与匿名同段位基准。
- 带比赛/回合证据的个性化建议。

### 不支持

- 中国大陆《无畏契约》。
- 死斗、极速、自定义和非竞技模式分析。
- 他人完整战绩查询或战绩分享链接。
- 赛前对手侦察。
- 实时提示、覆盖层或会改变当前对局决策的功能。
- 自定义 MMR/ELO 或官方段位替代系统。

## 3. 用户流程

```text
产品登录 -> 连接 Riot 账号 -> RSO 授权 -> 获取 PUUID
-> 同步竞技对局 -> 计算指标 -> 查看复盘 -> 追问 Agent
-> 保存训练目标（需用户确认）
```

## 4. Agent 任务

Agent 需要处理：

- “我最近为什么总是先死？”
- “我在这张地图的防守问题是什么？”
- “我的高 ADR 为什么没有转化为更多击杀？”
- “我应该优先练枪法、站位还是经济决策？”

每条回答必须包含：结论、证据、置信度、建议、数据限制。没有足够样本时必须明确表示无法判断。

## 5. 功能验收标准

- 玩家只能看到自己的 Riot 数据。
- 同步任务可重试且不会重复插入对局。
- 非竞技对局不会进入分析数据集。
- 指标可以从总览钻取到比赛和回合证据。
- Agent 不会响应他人查询、赛前侦察或实时指挥请求。
- 每次 Agent 分析有可查询的 trace。
- 每条洞察可以定位到结构化统计或具体回合。
